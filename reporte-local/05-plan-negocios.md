# 05 — Plan de negocios (portfolio freelance, 7 rubros)

## Oferta

Un sitio por rubro con demo viva que resuelve 1 objeción: clínica (preparación + turnera), concesionario (VDP + cuota + test drive), lavadero+bar (reserva + seña + carta), estética+yoga (1 BOOK + antes/después), universidad (buscador + visita), inmobiliaria (ficha + tour + WhatsApp), arquitectura (obra + planos + cotizar).

Cada demo incluye: hero video que se encoge, 1 sección pinned, 1 conversión punta a punta con ticket, CTA fijo mobile + WhatsApp con mensaje prearmado, prueba local (mapa, caso, reviews), legales AR (arrepentimiento/baja, Defensa Consumidor, precios finales).

## Pricing AR sugerido (a validar con tus costos)

- Landing demo → sitio cliente: desde USD 300 / ARS equivalente (1-2 semanas, contenido cliente, deploy Vercel).
- Sitio + conversión real (reserva/pagos/turnos conectados): USD 600-1200.
- Pack Fotos + copy + SEO local: +USD 200.
- Mantenimiento: USD 30-60/mes (hosting, cambios menores, backups, uptime). Hosting Vercel gratis al inicio, costo 0 hasta escalar.
- Referencia global: $250-897 por template/demo (Piedmondo, Horizon), ₹13k-30k India. Posicionate medio: más caro que template, más barato que agencia.

## Cómo venderlo

1. Portfolio filtrable por rubro (no por tecnología). Cada card: problema → demo → resultado.
2. Demo gratis de tu negocio (como Horizon): formulario “te armo tu home en 48h” con captura.
3. SEO local + WhatsApp: ficha Google, `tel:`, `wa.me` con texto por rubro.
4. Prueba: 2-3 casos con métricas (turnos, visitas, llamados). Sin métrica no hay venta.

## Qué no hacer

No vendas réplica 1:1 (thaloz/invgate) como producto final: úsalo como benchmark interno. No prometas backend real en plan base: cotizalo aparte (Resend/Formspree/Supabase/MercadoPago).
